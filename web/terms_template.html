利用規約・データの扱い

このサイト（カルカソンヌAI研究）と、対戦ページから送ってもらう棋譜の扱いを決めたものです。棋譜を送る前に読んでください。

制定・施行: 2026年11月12日

要点

送るのは自由です。送らなくても、対戦・再生・学習ページはすべて使えます。

送った棋譜は公開されます。「みんなの対局」ページに載り、誰でも見られ、CC BY 4.0 で誰でも使えるデータになります。

送ったあとで消すことはできません。名前などが入っておらず、誰の対局か見分けられないためです。

名前や連絡先は集めません。送る中身にも書き込まないでください。

1. この規約について

この規約は、個人の研究プロジェクト carcassonne-research（以下「運営者」）が公開するこのサイトと、対戦ページから送ってもらう棋譜に適用します。サイトを使ったとき、または棋譜を送ったときに、この規約に同意したものとします。

2. 棋譜を送るとき

  1. 棋譜を送るかどうかは自由です。送らないことで不利になることはありません。
  2. 送る中身は、山札の並び・指し手・得点・AIの強さと版・初心者モードの有無・ヒントと「待った」の回数だけです。名前・メールアドレスなどは入りません。
  3. 送り方は2つあり、どちらも外部のサービスを使います。それぞれのサービスの規約とプライバシーポリシーも適用されます。
    • 「規約に同意して送る（アカウント不要）」は Google フォームです。運営者が受け取るのは送信の時刻と棋譜だけで、メールアドレスは集めません。回答の表は、取り込みのためにウェブで公開しています。
    • 「規約に同意してGitHubで送る」は GitHub の Issue です。棋譜と一緒に、あなたの GitHub のアカウント名が公開されます。
  4. 送るときの画面に、名前・連絡先など、あなたや他の人が分かることを書き込まないでください。棋譜の形でないものは取り込みません。
  5. 送られた棋譜は、ルールどおりか確かめてから取り込みます。確かめられなかったものは取り込みません。

3. 公開と利用への同意

棋譜を送ることで、あなたは次のことに同意します。

  1. 棋譜が「みんなの対局」ページなどで公開され、誰でも見られること。
  2. 棋譜が、AIの学習・弱点の分析・研究と、その結果の公開に使われること。
  3. 棋譜が、下の「5. データのライセンス」の条件で、誰でも使えるデータとして配られること。
  4. 棋譜に権利が生じる場合、あなたは運営者に、その棋譜を無償で、期間を定めず、取り消せない形で使うこと（公開・加工・再配布と、CC BY 4.0 での提供を含む）を許し、運営者とデータの利用者に対して著作者人格権を行使しないこと。

4. 送ったあとの削除・訂正

送った棋譜の削除・訂正の依頼は受け付けません。棋譜には名前などが入っておらず、誰が送った対局かを見分けられないためです。また、集めたデータを研究の記録として失わないよう、消さずに保管します。送る前に、公開されてよいかを確かめてください。

5. データのライセンス

集めた人との対局の棋譜（human_games.json、data/human_games.jsonl）は、クリエイティブ・コモンズ 表示 4.0 国際（CC BY 4.0）で公開します。出典を表示すれば、営利・非営利を問わず、誰でも複製・再配布・加工して使えます。

表示の例: 「carcassonne-research 人との対局データ（CC BY 4.0）」と、このサイトへのリンク。加工した場合は、加工したことも書いてください。

このデータ以外の文章・プログラム・画像については、このページではライセンスを定めていません。

6. 個人情報

  1. 運営者は、名前・メールアドレスなど、特定の個人を識別できる情報（個人情報保護法の「個人情報」）を集めない作りにしています。
  2. 対戦ページは、最近の対局（20局まで）・言語・設定を、あなたのブラウザの中（localStorage）に保存します。これは運営者には送られず、ブラウザのデータを消すと消えます。
  3. ページの表示に、Google Fonts（文字の形）を読み込むことがあります。そのとき、あなたのブラウザが Google に接続します。
