# 研究の「次にやること」一覧

毎日の研究の回（satou-aaaaa/shared-workflows の `routines/research-loop.md`）が、ここから1件ずつ選んで進める。
人が研究を頼んだスレッドも、始める前にここに項目を足し（または「作業中」にし）、終わったら「済み」にして結果を書く。
書き方は `tests/test_backlog.py` が確かめる。

- 見出しは `## R-<3桁の番号> <題>`。番号は使い回さない。
- `- 状態:` 次 / 作業中 / 済み / 保留 / やめた。作業中は1件まで。
- `- 優先:` 1（先にやる）〜 5。同じなら番号の若い順。
- `- 待ち:` 先に済んでいてほしい項目の番号（あれば）。
- `- 完了条件:` 何がそろえば済みか（対局数・比べる相手・記録する場所）。必ず書く。
- `- 手がかり:` 前の結果・メモ・出典。
- `- 実行:` 重い計算を Actions（`research-run.yml`）で回しているときの名前。結果はブランチ `research-results` の `runs/<名前>/`。
- `- 結果:` 済みにしたとき、PR 番号と1行の結論（効かなかったときも書く）。
- `- 保留の理由:` 保留にしたとき、何が決まれば・そろえば再開するか。
