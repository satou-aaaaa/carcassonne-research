# 研究の「次にやること」一覧

毎日の研究の回（satou-aaaaa/shared-workflows の `routines/research-loop.md`）が、ここから1件ずつ選んで進める。
人が研究を頼んだスレッドも、始める前にここに項目を足し（または「作業中」にし）、終わったら「済み」にして結果を書く。
書き方は `tests/test_backlog.py` が確かめる。

- 見出しは `## R-<3桁の番号> <題>`。番号は使い回さない。
- `- 状態:` 次 / 作業中 / 済み / 保留 / やめた。作業中は1件まで。
- `- 優先:` 1（先にやる）〜 5。同じなら番号の若い順。
- `- 待ち:` 先に済んでいてほしい項目の番号（あれば）。
- `- 完了条件:` 何がそろえば済みか（対局数・比べる相手・記録する場所）。必ず書く。
- `- 手がかり:` 前の結果・メモ・出典。
- `- 実行:` 重い計算を Actions（`research-run.yml`）で回しているときの名前。結果はブランチ `research-results` の `runs/<名前>/`。
- `- 結果:` 済みにしたとき、PR 番号と1行の結論（効かなかったときも書く）。
- `- 保留の理由:` 保留にしたとき、何が決まれば・そろえば再開するか。

## R-013 探索の値を教師にして評価を学ぶ（Expert Iteration）を試す
- 状態: 済み
- 優先: 1
- 完了条件: 今の学習目標（終局の得点差からの TD(λ)）の代わりに、各局面で深く探索した根の値（予想最終点差）を教師にして線形評価を学ぶ。先生を固定せず、学んだ評価で探索し直して教師を作り直す反復を2回以上回し、各回の評価を今のチャンピオンと同じ探索で先後入れ替え200局以上比べる（伸びが続くか・頭打ちになるかを見る）。docs/EXPERIMENTS.md に書く。
- 実行: r013-exit-20261120（`scripts/sweeps/r013_exit.sh`、道具は `scripts/exit_iter.py`）
- 手がかり: AlphaZero・Expert Iteration（Anthony ら 2017）は探索の結果を次の評価・方策の教師にして、先生（評価＋探索）と生徒（評価だけ）の差で伸びる。線形評価は検証R²≈0.3〜0.4で頭打ちの恐れがある（selfplay ループの記録）。過去に効かなかったもの（盤面CNN・全データ学習・確率節点・depth=15）は繰り返さない。
- 結果: 本PR。効かなかった。根の値だけを教師にすると gen1373 に 0.393・−5.3点、根の値とTD(λ)を半々で 0.450・−2.9点、対照の TD(λ) は 0.495・+0.9点。反復2（反復1の版で探索し直した教師）は 0.425・−3.1点で、反復1の版にも 0.468 と伸びず、反復するほど弱くなった。2000回の探索の根の値は評価関数そのものとの相関が0.96と高く、先生と生徒の差が小さい一方、10手のランダムなロールアウトの癖まで学んでしまう。先生を12000回の探索にした追試（400局）も 根の値だけ 0.395・半々 0.463 で同じく弱くなった。docs/EXPERIMENTS.md「2026-11-20 探索の値を教師にした学習（Expert Iteration）」、`docs/results/exit_iteration.json`。
