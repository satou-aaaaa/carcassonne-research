強いAIは、どこに置いているか

このプロジェクトで作った一番強いAI同士を48局戦わせ、全部の手を記録しました。比べる相手は「その手番で一番点が増える手を選ぶだけのAI」（以下、目先の点だけのAI）です。強いAIがこのAIと同じ手を選んだのは40%だけでした。残りの60%の手に、初心者がまねできるコツが詰まっています。

  • 強いAI同士 48局
  • 目先の点だけのAI同士 200局
  • 1人あたり平均得点 87点（目先の点だけのAIは79点）
  1. ミープル
    全部使い切らずに手元に残す
    道には「すぐ終わる道」だけ
    都市は自分で新しく始める
    農民は1人3〜4個、早めに1つ
  2. タイル
    相手の都市に合流して分け合う
    相手の都市を「完成しない形」にする
    修道院は周りを自分で埋める
  3. 得点
    勝ち負けを分けるのは都市
    まとめ

ミープル7個をどう使うか

ミープルは7個しかありません。強いAIの差がいちばん大きく出たのは、この使い方でした。

全部使い切らずに、1〜2個は手元に残す

置ける場所があるとつい置きたくなりますが、強いAIは置けるのに置かない手が目先の点だけのAIより多く、序盤の終わりでも手持ちが残っています。手元に1個あれば、相手の都市への合流や、終盤の大きな草原など「ここぞ」という場面に使えます。

強いAI23%
目先の点だけのAI9%
手持ちがあるのに、あえてミープルを置かなかった手番の割合

手持ちミープル数の平均（手番を迎えたとき）。山札の残りが48枚の時点で、強いAIは平均1.8個、目先の点だけのAIは0.5個。

道に乗せるのは「すぐ終わる道」だけ

道は1タイル1点と安く、端が決まらないといつまでも完成しません。強いAIが道にミープルを置くのは、ほとんどが既にある道を延ばす場面で、置いたミープルはすぐに戻ってきます。新しい道を自分から始めることはまずありません。

強いAI6.7手番
目先の点だけのAI14.8手番
道に置いたミープルが戻ってくるまでの平均（強いAIの道ミープルの98%は既存の道に乗せたもの）

ミープルを置いてから戻るまでの平均手番数（自分の手番で数える）。農民は終局まで戻りません。

都市は、自分で新しく始めて育てる

強いAIは置いたミープルの41%が都市でした（目先の点だけのAIは35%）。しかも半分以上は、まだ誰のものでもない新しい都市の1枚目に乗せています。完成した都市は1タイル2点、盾はさらに2点と高く、自分だけの都市なら他人に邪魔されにくいからです。

強いAI57%
目先の点だけのAI30%
都市に置いたミープルのうち、新しい都市（どこにもつながっていない都市）に置いた割合

農民は1人3〜4個。序盤から1つ確保し、最後の1個も農民へ

農民（草原のミープル）は終局まで戻ってきませんが、1個あたり平均10.6点と、どの置き方より多く稼ぎます。強いAIはだいたい最初の数手で1つ目の農民を置き、終盤に残った最後のミープルも、完成した都市にたくさん接する草原へ置きます。農民の点は1人あたり平均18点で、全体の21%を占めます。

農民1個の平均得点10.6点
0点に終わった農民12%
強いAIの農民（1人1局あたり平均3.5個、平均21手番のあいだ盤上に残る）

タイルどこに置くか

強いAIは、自分の特徴を伸ばすだけでなく、相手の特徴にも手を出します。相手の特徴に接するタイルを置いた手番は強いAIが16%、目先の点だけのAIが11%でした。

相手の大きな都市には、合流して分け合う

相手の都市にミープルがいると直接は置けませんが、隣に自分の小さな都市を作ってミープルを置き、あとでタイルでつなげれば合流できます。ミープルの数が同じなら両方が満点をもらえます。強いAIの対局では、全得点の14%がこうした「分け合い」でした。

相手の都市を「完成しない形」にする

都市の隣に、残りのタイルでは埋められない穴を作ると、その都市はもう完成しません。完成すれば1タイル2点の都市が、終局時には1タイル1点に下がります。強いAIはこの手を目先の点だけのAIの2倍以上指していました。

強いAI0.33回
目先の点だけのAI0.15回
1人1局あたり、相手の都市を完成不能にした回数

修道院は、周りを自分で埋めて9点を取りに行く

修道院のミープルは平均8.3点を取りますが、48%は終局まで完成しません。強いAIは修道院の周りが空いていると、自分のタイルで埋めにいきます。

得点何で差がつくか

勝ち負けを分けるのは都市

勝った側と負けた側の点を得点源ごとに比べると、差のほとんどは都市から生まれていました。都市は勝った側が平均11点多く、道は3点、修道院は2点、草原は1点の差でした。迷ったら、自分の都市を完成させる手を優先しましょう。

強いAI同士の対局で、勝った側と負けた側が得点源ごとに取った平均点

まとめ

  1. ミープルは全部使い切らず、1〜2個は手元に残す。
  2. 道に乗せるのは、すぐ終わりそうな道だけ。
  3. 都市は自分で新しく始めて育てる。勝敗の差はほとんど都市で生まれる。
  4. 農民は早めに1つ。最後の1個は、完成した都市にたくさん接する草原へ。
  5. 相手の大きな都市には合流して分け合い、必要なら完成しない形にする。
  6. 修道院の周りは自分で埋めて、ミープルを早く取り戻す。

このページの数字について

  • 強いAIは、対人用の「最強」と同じ設定（モンテカルロ木探索12000回＋10手の先読み＋学習した評価関数）です。人間の上級者の打ち方とは違う癖もあり得ます。
  • 強いAIは48局と少なめなので、数%の差は誤差の範囲です。このページでは差の大きい傾向だけを取り上げました。
  • ルールは基本セット・2人対戦、農民は完成した都市1つにつき3点（第3版）です。
  • 再現方法: scripts/record_habits.py で記録、scripts/summarize_habits.py で集計、scripts/pick_examples.py と scripts/build_tips_page.py でこのページを作成。
