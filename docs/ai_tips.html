強いAIは、どこに置いているか

このプロジェクトでいま一番強いAI（gen1024、2026-11-08 採用。対戦ページの「最強」と同じAIです）同士を48局戦わせ、全部の手を記録しました。比べる相手は「その手番で一番点が増える手を選ぶだけのAI」（以下、目先の点だけのAI）です。強いAIがこのAIと同じ手を選んだのは31%だけでした。残りの69%の手に、初心者がまねできるコツが詰まっています。

  • 強いAI同士 48局
  • 目先の点だけのAI同士 200局
  • 1人あたり平均得点 91点（目先の点だけのAIは79点）

ミープル7個をどう使うか

ミープルは7個しかありません。強いAIの差がいちばん大きく出たのは、この使い方でした。

序盤に一気に使い切らない

置ける場所があるとつい置きたくなりますが、強いAIは置けるのに置かない手が目先の点だけのAIより多く、使うペースがゆっくりです。序盤の終わり（山札の残り48枚）でも平均1.6個が手元に残っています。手元に1個あれば、相手の都市への合流や、大きな草原など「ここぞ」という場面に使えます。中盤以降は強いAIもほぼ使い切る（残り24枚で平均0.9個）ので、ずっと温存するのではなく「急いで全部置かない」と考えてください。

手持ちがあるのに、あえてミープルを置かなかった手番の割合

手持ちミープル数の平均（手番を迎えたとき）。山札の残りが48枚の時点で、強いAIは平均1.6個、目先の点だけのAIは0.5個。

道に乗せるのは「すぐ終わる道」だけ

道は1タイル1点と安く、端が決まらないといつまでも完成しません。強いAIが道にミープルを置くのは、ほとんどが既にある道を延ばす場面で、置いたミープルはすぐに戻ってきます。新しい道を自分から始めたのは、道に置いたミープルの19%だけです。

目先の点だけのAI14.8手番
道に置いたミープルが戻ってくるまでの平均（強いAIの道ミープルの81%は既存の道に乗せたもの）

ミープルを置いてから戻るまでの平均手番数（自分の手番で数える）。農民は終局まで戻りません。

都市は、自分で新しく始めて育てる

強いAIは置いたミープルの43%が都市でした（目先の点だけのAIは35%）。しかもその63%は、まだ誰のものでもない新しい都市の1枚目に乗せています。完成した都市は1タイル2点、盾はさらに2点と高く、自分だけの都市なら他人に邪魔されにくいからです。

目先の点だけのAI30%
都市に置いたミープルのうち、新しい都市（どこにもつながっていない都市）に置いた割合

農民は数を絞り、完成した都市の多い草原へ

農民（草原のミープル）は終局まで戻ってきませんが、1個あたり平均11.0点と、どの置き方より多く稼ぎます。それでも強いAIが1局に置く農民は平均2.3個で、目先の点だけのAI（3.3個）より少なめです。序盤・中盤・終盤に平均0.9個・0.5個・0.9個と分けて置き、終盤は手元に戻ってきたミープルを、完成した都市にたくさん接する草原へ置きます。

農民は数より場所です。勝った側と負けた側の草原の点の差は平均+1点で、AIの世代や対局の運で大きくも小さくもなります（何で差がつくか）。序盤に置きすぎて都市に使うミープルが足りなくならないようにしつつ、完成した都市が集まりそうな草原を見つけたら置きましょう。

タイルどこに置くか

強いAIは、自分の特徴を伸ばすだけでなく、相手の特徴にも手を出します。相手の特徴に接するタイルを置いた手番は強いAIが16%、目先の点だけのAIが11%でした。

相手の大きな都市には、合流して分け合う

相手の都市にミープルがいると直接は置けませんが、隣に自分の小さな都市を作ってミープルを置き、あとでタイルでつなげれば合流できます。ミープルの数が同じなら両方が満点をもらえます。強いAIの対局では、全得点の16%がこうした「分け合い」でした。

相手の都市を「完成しない形」にする上級

都市の隣に、残りのタイルでは埋められない穴を作ると、その都市はもう完成しません。完成すれば1タイル2点の都市が、終局時には1タイル1点に下がります。強いAIはこの手を目先の点だけのAIの5.9倍指していました。

強いAIは1人1局あたり平均0.91回（48局で87回）この手を指しています。ただし残りのタイルを数えないと狙えない手です。初心者のうちは、まず自分の都市を完成させることを優先し、「置き場所に迷ったら相手の都市の邪魔になる場所も考える」くらいで十分です。

強いAI0.91回
目先の点だけのAI0.15回
1人1局あたり、相手の都市を完成不能にした回数

修道院は、周りを自分で埋めて9点を取りに行く

修道院のミープルは平均8.4点を取りますが、46%は終局まで完成しません。強いAIは修道院の周りが空いていると、自分のタイルで埋めにいきます。

得点何で差がつくか

勝った側は都市で積み上げる

勝った側と負けた側の点を得点源ごとに比べると、勝った側は都市でも多く取っていました。勝った側から見た差は、都市 +10点、草原 +1点、修道院 +2点、道 +1点です。都市以外の差は、AIの世代や対局の運で順位が入れ替わったり逆になったりする程度で、1つの決め手より積み重ねで勝っています。草原の点も完成した都市から生まれるので、その土台は都市です。迷ったら、自分の都市を完成させる手と、完成した都市に接する草原を押さえる手を優先しましょう。

強いAI同士の対局で、勝った側と負けた側が得点源ごとに取った平均点

まとめ

  1. ミープルは序盤に一気に使い切らない。序盤の終わりに1〜2個残っているくらいがよい。
  2. 道に乗せるのは、すぐ終わりそうな道だけ。
  3. 都市は自分で新しく始めて育てる。勝った側は都市でも多く取る（草原の点も完成した都市から生まれる）。
  4. 農民は数を絞る。終盤に余ったミープルは、完成した都市にたくさん接する草原へ。
  5. 相手の大きな都市には合流して分け合う。慣れてきたら、完成しない形にする手も考える。
  6. 修道院の周りは自分で埋めて、ミープルを早く取り戻す。

読んだら、手を動かして身につけましょう。次の一手クイズでAIと同じ手を選べるか試し、AIとの対戦ではヒントを見ながら、ここに書いたコツを1局に1つずつ意識してみてください。
