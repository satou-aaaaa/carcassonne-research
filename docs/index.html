はじめてのカルカソンヌ

タイルをつなげて地図を作るボードゲーム「カルカソンヌ」を、ルールを知らないところから一歩ずつ。このプロジェクトで作った強いAIと対戦でき、その対局から分かったコツと練習問題もあります。

AIと対戦する講座を1章から読む

3つの部

  • 講座ルール入門・戦略ガイド・強いAIのコツ・次の一手クイズの4章。ルールを知らない人から、上達したい人まで。講座の目次へ
  • 研究強いAIどうし・人とAIの対局を集計して分かったこと。先手の有利、点の出どころ、人が外しやすい局面。研究の目次へ
  • AIと対戦いちばん強いAIと1対1で遊べます。インストール不要。初心者モードでは自分の手が何点損だったかも分かります。対戦をはじめる

おすすめの進め方: 講座の1章「ルール入門」で遊び方を覚えたら、2章「戦略ガイド」の「まず覚える5つ」を読み、4章のクイズの入門編を解いてから、AIと対戦（初心者モード）で損した手を振り返ってください。
