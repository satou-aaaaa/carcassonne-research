カルカソンヌ入門ルール入門強いAIのコツ次の一手クイズAIと対戦

はじめてのカルカソンヌ

タイルをつなげて地図を作るボードゲーム「カルカソンヌ」を、ルールを知らないところから一歩ずつ。このプロジェクトで作った強いAIの対局をもとにしたコツと練習問題もあります。

  1. ルール入門手番の流れ、タイルとミープルの置き方、点の数え方を図で説明します。
  2. 強いAIに学ぶコツ強いAI同士の対局を集計して分かった、初心者がまねしやすい打ち方。
  3. 次の一手クイズ入門編から実戦編まで。AIならどこに置くかを当てて、解説を読みます。
  4. AIと対戦このプロジェクトでいちばん強いAIと1対1で遊べます。初心者モードでは自分の手が何点損だったかも分かります。

AIとの対戦はインストール不要で、AIはお使いのブラウザの中で考えます（最強設定は1手に数秒かかることがあります）。ルールは基本セット（72枚）の現行ルールです。
