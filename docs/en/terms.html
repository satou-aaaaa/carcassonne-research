These terms cover this site (Carcassonne AI research) and the game records sent from the play page. Please read them before sending a game.

Established and effective: November 12, 2026

Key points

Sending is optional. Without sending anything, you can still use the play page, replays and all learning pages.

Games you send are published. They appear on the Community Games page, anyone can see them, and they become data anyone can use under CC BY 4.0.

Games cannot be removed after sending. They contain no names, so we cannot tell whose game is whose.

We do not collect names or contact details. Please do not write them into what you send.

2. Sending a game record

  1. Sending a game record is up to you. You are not disadvantaged in any way if you don't.
  2. A record contains only the deck order, the moves, the scores, the AI level and version, whether beginner mode was on, and the number of hints and undos. It contains no names or email addresses.
  3. There are two ways to send, and both use outside services. Their own terms and privacy policies also apply.
    • "Agree to the terms and send (no account needed)" uses a Google Form. The operator receives only the time of sending and the record, and does not collect email addresses. The response sheet is published on the web so the records can be imported.
    • "Agree to the terms and send via GitHub" uses a GitHub Issue. Your GitHub account name is published together with the record.
  4. Do not write anything on the sending screen that could identify you or anyone else, such as names or contact details. Anything that is not a game record is not imported.
