カルカソンヌ講座

ルールを知らないところから、強いAIのような打ち方まで、4つの章で順に進みます。各章の終わりに次の章へのリンクがあります。

  1. 1章 ルール入門手番の流れ、タイルとミープルの置き方、点の数え方を図で説明します。
  2. 2章 戦略ガイドルールを覚えたら次はここ。点差で考える土台、タイルの内訳、埋まりにくい穴、序盤・中盤・終盤の方針、よくある失敗、用語集。
  3. 3章 強いAIに学ぶコツ強いAI同士の対局を集計して分かった、初心者がまねしやすい打ち方。
  4. 4章 次の一手クイズ入門編から実戦編まで。AIならどこに置くかを当てて、解説を読みます。
  5. 仕上げ AIと対戦初心者モードで対戦すると、自分の手のあとにAIならどこに置いたかと何点損したかが出ます。

急ぐ人は、1章のあと2章の「まず覚える5つ」だけ読んで、4章の入門編に進んでもかまいません。慣れてきたら3章と4章の実戦編へ。
