# ルール定義（基本セット・2人対戦）

エンジンが実装するルールの正本。曖昧な点は「未解決」に列挙し、決定したらここに追記する。
出典: Wikipedia "Carcassonne (board game)"、Uppsala大学の分析記事、既存実装（wingedsheep/carcassonne）。
**印刷版ルールブック（2版以降の日本語/英語版）との突き合わせは未了。**

## 構成
- タイル: 72枚（開始タイル1枚＋山札71枚）。タイルは辺ごとに 都市/道/草原 を持ち、
  盾（ペナント）・修道院・道の分岐（交差点）を持つものがある。
- ミープル: 各プレイヤー7個（得点トラック用の8個目は盤上に置かない）。2人対戦のみ。

## 手番
1. 山札から1枚引く。
2. 既に置かれたタイルに辺で隣接するよう、回転（90度刻み）して配置する。
   接する辺はすべて同種（都市-都市、道-道、草原-草原）でなければならない。
3. （任意）今置いたタイル上の地形に、自分のミープルを最大1個置く。
   その地形が（すでに繋がっている範囲で）他のミープルに占有されていないことが条件。
4. 完成した特徴を得点計算し、ミープルを回収する。

## 得点（完成時）
- 都市: 1タイルにつき2点＋ペナント1つにつき2点。
- 道: 1タイルにつき1点。
- 修道院: 自身＋周囲8マスの計9マスが埋まれば9点。
- 複数のミープルが同一特徴にいる場合は最多の側が得点（同数なら両者満点）。

## 得点（終了時）
- 未完成の都市: 1タイルにつき1点＋ペナント1つにつき1点。
- 未完成の道: 1タイルにつき1点。
- 未完成の修道院: 1点＋周囲の埋まっているマス数。
- 農民（草原）: 隣接する**完成した**都市1つにつき3点（現行3版ルール）。
  完成都市に接しない草原は0点。

## 終了
山札が尽き、最後のタイルを置いて得点処理をしたら終了。

## 実装上の決定（エンジンに反映済み）
1. 置けないタイルを引いた場合: 捨てて（以後使わない）次を引き直す。手番プレイヤーは変わらない。
   置けるタイルが引けないまま山札が尽きたら終局。
2. 農民の接続: タイルの辺を2つの「半辺」に分け、道で区切られた草原を別の断片として表す。
   隣接する半辺同士を連結する（`data/tiles.json`、`src/carcassonne/tiles.py`）。
3. 最多判定: ミープル数が最多のプレイヤーが得点。同数なら両者に満点。
4. ミープルの手持ちが0個のときは置けない。完成特徴のミープルは得点後に手持ちへ戻る。
5. 完成する特徴に置く手も合法として残す（現実のルール上は合法。AI側で必要なら枝刈りする）。
6. 山札の残りの並びは非公開、残りタイルの内訳（種別ごとの枚数）は公開情報として扱う。

## 検証の状況
- 得点・連結は、Union-Findを使わない独立の素朴オラクル（`tests/oracle.py`）との差分テストで全手一致を確認済み。
  ただしタイル定義は共有するため、定義自体の正しさは枚数表との照合に依存する。
- 外部の独立実装（JCloisterZone等）との得点突き合わせは未実施（ネットワーク/Java環境が必要）。
