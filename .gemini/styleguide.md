# レビューの決まり

- レビューのコメントは必ず日本語で書く（英語にしない）。
- このリポジトリの PR は Claude のエージェントが作り、CI が緑なら人の確認なしにマージされる。
  だから、動きの誤り・データが壊れる・セキュリティ・テストや検査の抜けを優先して指摘する。
- 好みの書き方・言い回し・細かい整形は指摘しない（整形とリンターは CI が見る）。
- 指摘には、どの入力・どの手順でどう壊れるかを1〜2文で書く。たどれない推測は書かない。
- コメントや画面の文言の言い回し・言語を変える提案はしない（言葉選びは持ち主が決めている）。
- `docs/*.html`（`docs/index.html` を除く）は `scripts/build_pages.py` の生成物。
- 強さの主張（勝率・昇格）は、対局数と統計の検定（SPRT など）が添えられているかを見る。
